### Component 4: Realtime Layer (Cloud Firestore)

- **Pattern:** Ephemeral document sessions secured by role-based path security rules.

## Data Flow

1. **Authentication Flow:** User authenticates via Firebase Auth on `signin.html`. Client exchanges ID token for backend session token.
2. **Attendance Marking Flow:** Faculty opens attendance session $\to$ backend generates rotating HMAC-SHA256 token $\to$ student scans QR / enters challenge code $\to$ backend verifies geo-proximity and 20-second validity $\to$ commits attendance record into PostgreSQL.
3. **Audit Trail Flow:** High-privilege actions (grade updates, attendance overrides, user suspensions) invoke trigger-based linear SHA-256 hash chaining ($H_i = \text{SHA-256}(H_{i-1} \parallel \text{payload}_i)$).
